# Портфолио-лендинг — задачи и прогресс

**Цель:** максимально дешёвый и хороший сайт-визитка с услугами Филиппа Московцева (веб-разработка). Разместить в интернете.

## Стек / хостинг (цель — дёшево)
- Статический HTML (`index_2.html`) — один файл, без сборки.
- Хостинг: бесплатный статик (GitHub Pages / Netlify / Cloudflare Pages) — 0 ₽.
- Форма заявок: Formspree (бесплатный тариф).

- [x] Шрифты (по образцу Fontjoy, русифицированы аналогами с кириллицей): заголовки — Scada, текст — PT Serif (аналог Maitree), метки/кнопки — Rubik (аналог Ruda). Через 3 CSS-переменные `--font-display/body/mono`.
- [x] 3D-иконка % в модалке скидки: из jpeg-рендера вырезан фон (keying по «красности» через chromium/canvas) и перекрашен в небесно-голубой → `assets/percent-3d.png` (прозрачный). Анимация: выезжает из глубины с 3D-вращением (perspective + rotateX/Y, cubic-bezier bounce), затем мягко парит; модалка едет slide+scale. `prefers-reduced-motion` выключает.
- [x] Песок «песочные часы» на форме: canvas `#sandfx` поверх модалки. С кучек на верхних углах прямоугольника непрерывно сыплются мелкие песочные струйки по обоим краям — падают вниз с гравитацией, часть переливается бликами, тают ниже формы. Живёт, пока модалка открыта (start на openModal после выезда, stop на closeModal). Лимит частиц, `prefers-reduced-motion` выключает.
- [x] Убрана кнопка «Обсудить проект» из hero.
- [x] Медузы: убраны рисованные canvas-спрайты. Фон — реальные фото-медузы с CSS-анимацией «плавания» (дрейф + пульсация купола + лёгкое вращение, 30с, поверх Ken Burns; base scale >1). На canvas остался только мягкий свет спор. `prefers-reduced-motion` выключает анимации.

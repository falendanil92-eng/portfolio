# Проект: портфолио-лендинг Филиппа Московцева

Одностраничный сайт-визитка с услугами веб-разработки. Цель — дёшево (бесплатный хостинг) и качественно.

- Главный файл: `index_2.html` (статик, один файл, без сборки).
- Прогресс и задачи: см. `PROGRESS.md`.
- Форма заявок: Formspree (endpoint пока заглушка `YOUR_FORM_ID`).
- Хостинг цель: GitHub Pages / Netlify / Cloudflare Pages.

## Рабочие правила (обязательно)
1. **После каждого редактирования кода / вставки нового элемента** — запускать сайт в браузере (авто-hook перезагружает Safari; при необходимости открыть/сделать скриншот через playwright-webkit).
2. **После каждого 3-го редактирования** — проверять код на баги: наложения текста/элементов, ошибки консоли, битые ссылки, поломки при открытой модалке и на мобилке. Чинить найденное до продолжения.
